OBJECT INTELLIGENCE & EXPLAINABLE RISK

Know what you're tracking

Click any object to open its intelligence profile: identity and classification, mission context where verified data exists, live orbital state computed from the actual TLE (altitude, velocity, inclination, apogee/perigee, period), data freshness with confidence scoring, and upcoming conjunction context from the event database. Debris is labeled honestly — no invented missions.

  • Payload / rocket body / debris classification
  • Live sub-satellite point & orbital elements
  • TLE age, freshness status and prediction confidence
  • Source transparency for every data layer

3D ENCOUNTER REPLAY

Replay any conjunction from T−30 minutes through T+30 on the Cesium globe: both trajectories, the closest-approach geometry, a live separation readout, follow-cam for either object, and jump-to-TCA controls. The simulation clock, timeline scrubber and globe stay perfectly synchronized.

AI SPACE INTELLIGENCE COPILOT

Ask "why is this conjunction high risk?" or "what was this satellite launched for?" The copilot answers only from verified system data plus a scientific knowledge base covering TLEs, SGP4, screening methodology and uncertainty. Without an AI key it still explains events deterministically — grounded, never invented.
